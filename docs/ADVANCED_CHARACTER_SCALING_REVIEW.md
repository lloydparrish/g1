# Advanced Character Scaling Review

This source-record comparison documents how the five advanced class profiles differ from their starter baselines. The finalization pass assigns their player-facing titles and authored unlock conditions while preserving every existing ability, aura, resource, attribute, growth profile and equipment value. This file remains a reference for a separate, user-led scaling discussion; none of the comparisons below authorize a balance change.

Values below reflect the current `data/content.json` records. Health, Mana and Stamina are starting maximums; attributes are Might / Dexterity / Vitality / Intelligence / Willpower / Perception. Ability counts are the current `known` lists. Armor is the current equipped armor total, including the Warrior's Iron Resolve bonus.

The new starters' weak-build targets are: The Mundane has a sword and no known abilities; The Archer has a basic bow and no known abilities; The Apprentice has a wand and Magic Missile; The Defender has a sword, shield and Shield Bash. They have no developed ability suite or armor loadout at run start (the Defender's defining shield is equipment, not armor).

For all five advanced profiles, current abilities, auras, resources, attributes and growth profiles remain unchanged. Final titles, static Treatment A portraits and authored unlocks are recorded in CONTENT_FOUNDATION.md. No Swordplay package content is implied by this comparison.
